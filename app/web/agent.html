给 Agent 一个任务

例如：把所有脚本的 print 换成 logger、给 app/services 下每个公开函数补 docstring 并跑 pytest 验证。
模型默认走 zk-auto；先在下面选好工作区和权限档，开工后就不再反复打断。

要让桌面应用干活，看这里：
· 改表格 / 文档 / PPT —— 直接描述任务就行，Agent 会自己调本机编辑器工具；
· 让 CodeBuddy、Qoder、Claude 等命令行工具干 —— 点下面的「选执行体」，或打 @ 挑一个；
· 右上角那个下拉是规划用的大模型，不是各工具自己的模型。
