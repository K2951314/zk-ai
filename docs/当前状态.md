## 配置与迁移纪律

- **`.env` 是运营配置，不是测试夹具**：绝不用 `read_text()` 读写它（CRLF 会被悄悄
  归一成 LF，半 LF 半 CRLF 混写就是事故）；要么全程字节，要么
  `open(..., newline="")`。门禁跑不了就停下来问，别为了跑测试改它。
  `malformed_env_names()` 是现成体检入口，返回空才算健康。2026-09-24 换机后那份
  `.env` 115 行全 `\r\r\n`，症状是网关 bind 失败却报 `getaddrinfo failed`。
- **导入迁移包前必须先停网关**（2026-09-21 为这条流过血）：换机包覆盖 `data/zkai.db`
  时，若同目录还留着上一代的 `-wal`/`-shm`，下次开库会把别人的 WAL 帧回放 →
  `database disk image is malformed`，**不是警告是真损坏**（本机 `requests`/
  `usage_records` 就是这么废的）。一键换机 Skill 的 `import` 会先备份 side-car 再删除；
  最稳仍是先从托盘退出网关再导入。验证损坏库要用 sqlite3 backup API 取一致快照再
  `PRAGMA integrity_check`——直接 `cp` 正在写的库必然报假阳性。
